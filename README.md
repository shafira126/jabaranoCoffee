<h3>2.1.  Deskripsi Aplikasi</h3>
  JabaQueue (ini masih sementara namanya jujur kureng) merupakan aplikasi desktop untuk membantu staf Jabarano Cafe mengelola antrean pelanggan dan penggunaan meja. Staf dapat mencatat data pelanggan, sementara sistem akan memberikan nomor dan posisi antrean secara otomatis. Sistem juga membantu pemilihan meja berdasarkan jumlah pelanggan, pemanggilan antrean, serta pemantauan status meja mulai dari tersedia hingga selesai digunakan. Seluruh data tersimpan dalam database MySQL dan ditampilkan melalui Java Swing.
